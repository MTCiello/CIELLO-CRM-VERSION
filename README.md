# CIELLO ERP — versões

Instaladores do CIELLO ERP para Windows (`CIELLO-Setup-X.Y.Z.exe`), publicados
automaticamente a cada nova versão. Veja em **Releases**.

O próprio CIELLO ERP confere este repositório a cada 12 horas e avisa o administrador quando
há uma versão nova (*Configurações → Atualizações*). Cada instalador vem com a impressão
digital (`.sha256`) e a assinatura, conferidas antes de instalar.
